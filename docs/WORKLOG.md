## 2026-07-22 — Аудит бэкенда и фронтенда, фиксы надёжности

Запущены два read-only агента (backend + frontend audit). Их находки проверены;
применены безопасные фиксы, каждый — с прогоном тестов.

### Применено (с проверкой)

**Backend**
- **[P0] Роль `admin` в `UserRole`.** DB-enum `user_role_enum` на проде уже содержал
  `admin` (ручная миграция), а Python-enum — нет → `LookupError` → 500 на КАЖДОМ
  запросе админа (не только логин; грузится в `get_user_by_email`). Добавлено
  `admin = "admin"` + идемпотентная миграция `f4a5b6c7d8e9`
  (`ADD VALUE IF NOT EXISTS` — безопасна и на проде, и на свежей БД).
- **[P1] v1 создание транзакции без guard на `IntegrityError`.** Гонка двух запросов
  с одним `Idempotency-Key` мимо Redis → второй `commit` падал 500. Обёрнут в
  try/except как в v2 — возвращаем уже записанную транзакцию.
- **[P1] Межтенантная утечка через `category_id`.** v1 брал категорию из payload без
  проверки владельца — можно было привязать транзакцию к чужой категории (порча
  данных + утечка чужого имени). Добавлена проверка владения (create + update) +
  регрессионный тест.
- **[P2] Access-log `user_id`.** `get_current_user` не проставлял `request.state.user_id`
  → в логах всегда `anonymous`. Исправлено.
- **[P2] Rate-limit на `POST /analytics/yearly`.** Аутентифицированный, но без лимита →
  можно спамить дорогими LLM-задачами. Добавлен `@limiter.limit("10/minute")`.

**Frontend**
- **[P0/P1] Надёжность синка игровых очков** (объясняет «то есть запись, то нет»).
  Корневая причина «то нет» на проде — старый код слал результат только при побитом
  локальном рекорде; исправлено ранее. Дополнительно: (а) 4-сек debounce терял
  результат при закрытии вкладки — добавлен flush на `pagehide`/`visibilitychange`
  через keepalive-fetch; (б) переотправка рекордов из localStorage теперь при КАЖДОМ
  открытии аркады (upsert идемпотентен) — страховка от потерянных фоновых отправок.
- **[P1] Мерцание сайдбара при скролле.** `transition-all` на `<aside>` с
  `backdrop-filter` анимировал сам блюр на каждом перерисовывании при скролле main →
  белое мерцание края. Заменено на `transition-transform` + `transform-gpu`
  (отдельный слой).
