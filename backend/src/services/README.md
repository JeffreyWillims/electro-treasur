# services

Бизнес-логика приложения — слой между API-роутами и ORM-моделями. Все финансовые
расчёты (health score, налоги, инсайты, психопаспорт) детерминированные и без LLM.

- `__init__.py` — маркер пакета, пустой.
- `ai_vision_service.py` — эвристический парсер выписок (PDF/фото/Excel) без LLM.
- `analytics_service.py` — аналитика и симулятор «что если».
- `api_key_service.py` — выпуск/проверка API-ключей (`cv_{prefix}{secret}`, префикс плейнтекстом+UNIQUE, секрет хешируется).
- `auth_service.py` — регистрация, логин, refresh/logout, работа с JWT.
- `budget_service.py` — установка и снятие лимитов бюджета по категориям.
- `cashflow_prep.py` — подготовка данных для месячного инсайта: чистые (unit-тестируемые без БД) хелперы периода + асинхронные обёртки доступа к БД для fan-out воркера.
- `dashboard_service.py` — агрегация дашборда за месяц одним SQL-запросом (O(N) по транзакциям).
- `email_service.py` — отправка писем через SMTP; без `ET_SMTP_HOST` пишет письмо в структурный лог.
- `feedback_service.py` — сохранение сообщения обратной связи пользователя.
- `health_score_service.py` — индекс финансового здоровья: чистая формула `compute_health_score` + асинхронный оркестратор, собирающий входные данные из БД.
- `import_export_service.py` — экспорт транзакций (JOIN → CSV с UTF-8 BOM) и импорт.
- `insight_engine.py` — `RuleBasedInsightEngine`: детерминированный «AI Анализ» без LLM, принимает dataclass-снимки транзакций/бюджетов, возвращает человечный многострочный текст.
- `pdf_report_service.py` — серверная генерация PDF «Личный финансовый план» (fpdf2, кириллица через DejaVuSans).
- `psychopassport.py` — финансовый психопаспорт: чистая функция, агрегаты периода → персона, наблюдения, советы.
- `tax_calculator.py` — доменная математика налогов Самозанятых/ИП (РФ): НПД, УСН и др. режимы.
- `tax_deduction_service.py` — калькулятор налоговых вычетов (13% от расходов, с учётом лимитов и уплаченного НДФЛ).
- `transaction_service.py` — идемпотентная запись транзакций (защита от дублей через Redis + UNIQUE в БД).
- `user_service.py` — CRUD пользователя и его категорий.
