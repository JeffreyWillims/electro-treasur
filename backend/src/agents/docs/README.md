# agents/docs

База знаний для агентов-разработчиков: две «плейбук»-инструкции для типовых задач
и по паре файлов (agent/rules) на каждую роль.

- `security_audit.md` — плейбук: аудит и модернизация кодовой базы (безопасность, приоритеты P0–P2).
- `feature_playbook.md` — плейбук: разработка новой фичи вертикальным срезом без поломок.
- `backend_agent.md` — инструкция Backend-агента: роль, workflow, команды верификации.
- `backend_rules.md` — жёсткие правила backend-кода (что можно/нельзя).
- `frontend_agent.md` — инструкция Frontend-агента.
- `frontend_rules.md` — жёсткие правила frontend-кода.
- `qa_agent.md` — инструкция QA-агента.
- `qa_rules.md` — жёсткие правила для тестов.
- `devops_agent.md` — инструкция DevOps-агента.
- `devops_rules.md` — жёсткие правила для инфраструктуры/CI.
