# api/analytics

Отдельные тяжёлые отчёты аналитики, вынесенные из `api/v1/analytics.py`, чтобы не
нагружать основной роутер.

- `__init__.py` — маркер пакета, пустой.
- `yearly.py` — годовая аналитика (строится по запросу, не по cron — см. память проекта
  про worker/report-топологию: «yearly» это on-demand эндпоинт, а не «nightly» cron).
