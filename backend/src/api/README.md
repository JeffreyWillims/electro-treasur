# api

HTTP-слой FastAPI: приватные роуты (`v1/`) и публичное API для внешних интеграций (`v2/`),
плюс подпакет расширенной аналитики (`analytics/`).

- `__init__.py` — маркер пакета, пустой.
- `v1/` — основной API приложения (авторизованные пользователи, httpOnly-cookie).
- `v2/` — публичный API (API-ключи, см. `v1/api_keys.py`).
- `analytics/` — отдельные тяжёлые/годовые отчёты аналитики.
