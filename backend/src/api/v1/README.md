# api/v1

Приватные роуты приложения (авторизация через httpOnly-cookie), собираются в
`router.py` под общим префиксом `/v1`.

- `router.py` — сборка всех роутеров v1 в один `APIRouter` + `GET /health` healthcheck.
- `analytics.py` — `GET /profile` (психопаспорт трат), `POST /simulate` (симулятор «что если»).
- `api_keys.py` — выпуск/отзыв API-ключей пользователя для публичного `/v2/public` (секрет виден один раз).
- `auth.py` — `/register`, `/login` (OAuth2 form), `/refresh`, `/logout` — httpOnly JWT-cookie.
- `budgets.py` — `PUT /` установить лимит бюджета по категории, `DELETE /{category_id}` снять лимит.
- `consultant.py` — RBAC-мост клиент↔консультант: гранты доступа и просмотр транзакций клиента.
- `dashboard.py` — `GET /` сводка дашборда за период (доходы/расходы/бюджеты по категориям).
- `feedback.py` — приём фидбэка: синхронный INSERT + асинхронная отправка письма в фоне.
- `games.py` — рекорды аркады: upsert очков, лидерборд по игре и общий зачёт.
- `goals.py` — цели «Сейф»: создание, список с прогрессом, пополнение (`contribute`), удаление.
- `health_score.py` — `GET /` индекс финансового здоровья 0..100 (детерминированный, без LLM).
- `imports.py` — импорт транзакций из выписок (PDF/фото/Excel) через arq-разбор с превью и подтверждением.
- `insights.py` — «AI Анализ»: постановка в очередь (arq), опрос последнего/истории инсайтов.
- `jobs.py` — SSE-стрим статуса фоновой arq-задачи (`pending` → `complete`/`error`/`timeout`).
- `notifications.py` — лента колокольчика (лениво досеивает «Что нового») + отметка прочитанного.
- `offers.py` — банковские предложения (депозиты) для Savings Navigator + счётчик кликов (CPA).
- `report.py` — `GET /financial-plan.pdf` серверная генерация PDF-отчёта «Личный финансовый план».
- `tax.py` — справочник «Налоги и вычеты»: полнотекстовый поиск норм (Postgres FTS) и расчёт.
- `transactions.py` — CRUD транзакций + экспорт/импорт (CSV).
- `users.py` — профиль текущего пользователя, CRUD пользовательских категорий, привязка Telegram (OTP).
- `__init__.py` — маркер пакета, пустой.
