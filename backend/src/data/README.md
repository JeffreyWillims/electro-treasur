# data

Статичные данные для наполнения (сидирования) базы данных.

- `__init__.py` — пустой файл-маркер пакета.
- `tax_seed.py` — список `TAX_RULES` со справочным контентом по налогам и вычетам (НДФЛ, вычеты, имущество, инвестиции, самозанятость) для таблицы `tax_rules`; используется миграцией сидирования и скриптом повторного наполнения.
