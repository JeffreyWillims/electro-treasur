# schemas

Pydantic V2 схемы (валидация запросов/ответов API), по одному файлу на предметную область.

- `__init__.py` — маркер пакета, пустой.
- `analytics.py` — схемы аналитики и симулятора «что если» (Savings Navigator).
- `api_key.py` — схемы API-ключей и публичного `/v2/public`.
- `budget.py` — схемы установки/чтения лимита бюджета по категории.
- `consultant.py` — схемы роли CONSULTANT (RBAC, доступ к клиенту только на чтение).
- `dashboard.py` — схемы агрегации дашборда: матрица Категория → План → Факт → Дельта → дни.
- `feedback.py` — схема сообщения обратной связи.
- `games.py` — схемы рекордов Citrine Arcade.
- `goal.py` — схемы целей «Сейф» (режим «Цель»).
- `health.py` — схема индекса финансового здоровья.
- `insight.py` — схемы эндпоинтов «AI Анализ».
- `notification.py` — схемы уведомлений колокольчика.
- `offer.py` — схемы банковских депозитных предложений (CPA Savings Navigator).
- `tax.py` — схемы справочника налоговых норм (полнотекстовый поиск).
- `token.py` — токены больше не возвращаются в теле ответа (уходят в httpOnly-cookie,
  см. `api/v1/auth.py`) — файл оставлен как маркер этого решения.
- `transaction.py` — схемы CRUD транзакций (строгая валидация Decimal, float по проводу отклоняется).
- `user.py` — схемы профиля пользователя и пользовательских категорий.
