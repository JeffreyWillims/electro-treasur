# tests/unit/

Юнит-тесты: изолированная бизнес-логика без БД, без Redis и без сети — чистые функции,
формулы, парсеры и сервисы с фейковыми/мок-зависимостями. Тесты этой папки должны
выполняться быстро и детерминированно, независимо от внешнего окружения.

## Файлы

- `__init__.py` — маркер пакета тестов (короткий комментарий на русском, без тестов).
- `test_agents.py` — агентная подсистема (`src/agents`, gitignored): реестр скиллов `SkillRegistry`, песочница `file_skills` (запрет выхода за project root, лимит размера файла), чистые `build_*`-команды и `run_command` в `test_skills`, загрузка инструкций/правил и fail-fast `verify()` у `BackendAgent`, реестр ролей `Orchestrator`; при отсутствии модуля весь файл скипается через `importorskip`.
- `test_analytics.py` — `simulate_savings()`: расчёт накоплений со сложным процентом, ускорение цели через `adjustments`/`habit_savings`, монотонный рост, лимит симуляции в 120 месяцев, крайние случаи (нулевые расходы, уже достигнутая цель).
- `test_api_key_service.py` — генерация API-ключей `generate_plain_key`/`extract_prefix`: формат, префикс, уникальность, отбраковка "мусорных" строк.
- `test_auth_dependency.py` — smoke-тест перехода на чистый Argon2 (после удаления passlib): формат хэша, verify правильного/неправильного пароля, уникальность хэшей за счёт соли, валидность dummy-хэша для защиты от timing-атак.
- `test_auth_service.py` — JWT (`create_access_token`/`decode_access_token`): payload, expiry, кастомный/дефолтный TTL, сохранность dict на входе, ошибки при истёкшем/подделанном/битом токене; плюс Argon2-хэширование паролей (уникальность, unicode-пароли, длинные пароли).
- `test_budget_math.py` — property-based тесты (Hypothesis) чистой функции `calculate_safe_to_spend` (дневной лимит трат): неотрицательность результата, обнуление при `days_left=0`, точность до 2 знаков, устойчивость к экстремальным суммам без переполнения, детерминированные ручные кейсы.
- `test_cashflow_prep.py` — `previous_month_range()`: границы предыдущего месяца, включая переход через год и високосный февраль.
- `test_health_score.py` — `compute_health_score()`: расчёт факторов (норма сбережений/цели/бюджеты) с весами, нейтральные значения при `None`, пороги итоговых оценок (grade) через параметризацию.
- `test_import_helpers.py` — `_resolve_columns` (сопоставление алиасов колонок RU/EN, регистронезависимость, обязательные/опциональные поля) и `_parse_amount` (разбор денежных значений: int/float/Decimal/строки с пробелами и запятой).
- `test_insight_engine.py` — `RuleBasedInsightEngine.generate()`: секции итогового плана — итог месяца со ставкой сбережений, дефицит, статус бюджетов (алерт на 80%, выбор наиболее превышенной категории), аномалия (много трат за день), рекомендации (нет доходов/дефицит/низкая норма сбережений/профицит), агрегаты `cashflow_totals`.
- `test_merchant_rules.py` — `resolve_merchant_category`: встроенный словарь мерчантов, отсутствие совпадения, расширение и переопределение правилами из БД, использование доп. правил при разборе чека `_parse_transactions_from_text`.
- `test_ocr_parsing.py` — парсинг OCR чеков/выписок в `ai_vision_service.py`: `_safe_parse_amount` (RU/US/EU денежные форматы, edge-кейсы, Hypothesis-фаззинг на отсутствие исключений), `_parse_transactions_from_text` (парсинг чеков и банковских выписок, система скоринга кандидатов 0–4, отбраковка дат/ИНН/годов, сопоставление категории по мерчанту, устойчивость к OCR-шуму, контракт полей вывода).
- `test_psychopassport.py` — `build_psychopassport()`: определение психотипа (`investor`/`saver`/`lifestyle_spender`/`survivor`/`balanced`) по долям расходов и норме сбережений, состав traits/recommendations, устойчивость к делению на ноль при нулевом доходе/расходе.
- `test_reminder_copy.py` — тексты напоминания «запиши траты за день»: тон по времени суток (дневной/вечерний пул), детерминированность, чередование между соседними днями, наличие примера ввода и отсутствие упрекающих формулировок.
- `test_reminder_worker.py` — arq-задачи `reminder_worker`: подсчёт успешных отправок и общего числа попыток в `remind_inactive_users`, пропуск пользователей без `chat_id` и формирование сообщения о свободных средствах в `push_free_funds` (зависимости `cashflow_prep`/Telegram-нотификатор замоканы).
- `test_schemas.py` — Pydantic-схемы транзакций: `TransactionCreate` (обязательные поля, границы `max_digits`/`decimal_places`, дефолты), `TransactionUpdate` (частичное обновление через `exclude_unset`, `None` как явное значение), `TransactionResponse`/`TransactionPaginatedResponse` (ORM-совместимость, дефолты опциональных полей).
- `test_services.py` — дашборд-агрегация по архитектуре Ports & Adapters: `FakeTransactionRepo` (in-memory реализация порта) + чистая `build_dashboard_from_data` — корректность доходов/расходов/дельт по категориям, размещение сумм по дням месяца, добавление транзакции через фейковый репозиторий, пустой репозиторий, тест производительности (< 10 мс).
- `test_statement_parse.py` — `parse_document_bytes`: извлечение кандидата-транзакции из сгенерированного PDF-чека, возврат `None` для пустого/нечитаемого PDF.
- `test_tax_calculator.py` — `calculate_tax`/`taxable_income`: ставки по налоговым режимам (НПД физ/юрлица, УСН «Доходы», УСН «Доходы минус расходы» с минимальным налогом 1% и убытком), округление до копейки, ошибки при отрицательных доходах/расходах, суммирование налоговой базы только по доходным категориям.
- `test_tax_deduction.py` — `calculate_deduction()`: расчёт налогового вычета (лечение, недвижимость, ипотека, ИИС, обучение ребёнка) с учётом социального/имущественного лимита, ограничение возврата уплаченным НДФЛ, ошибка на неизвестный вид вычета.
- `test_telegram_helpers.py` — чистые хелперы Telegram-бота (`handlers.py`): русские названия месяцев, очистка HEX-кодов из имён категорий, конвертация раскладки клавиатуры EN→RU, локализация системных категорий и эмодзи-оформление (`_display_cat`), диапазон текущего месяца, универсальный геттер атрибутов `_attr`, консистентность словаря синонимов категорий.
