# tests

Корень тестов бэкенда. Полное описание фреймворка, статистики и правил — в `TESTING.md`.

- `TESTING.md` — документация тестового фреймворка (287 тестов: unit/integration/e2e, покрытие, правила).
- `conftest.py` — основная тестовая инфраструктура: одно соединение с открытой транзакцией
  на всю сессию, каждый тест — свой SAVEPOINT (изоляция без пересоздания таблиц).
- `__init__.py` — маркер пакета, пустой.
- `unit/` — юнит-тесты (чистая логика, без БД) — см. `unit/README.md`.
- `integration/` — интеграционные тесты (с реальной БД) — см. `integration/README.md`.
- `e2e/` — сквозные тесты через настоящий браузер (Playwright).
- `factories/` — фабрики тестовых данных (factory_boy + Faker).
