# tests/e2e/pages

Page Object Model (POM) для E2E-тестов на Playwright: селекторы и действия
инкапсулированы здесь один раз, а не разбросаны по тестам — при смене `data-testid`
достаточно поправить только этот файл.

- `__init__.py` — маркер пакета, пустой.
- `login_page.py` — `LoginPage`: селекторы и действия для страницы `/login`.
