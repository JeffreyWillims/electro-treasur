# components/layout

Общий каркас приложения — навигация и виджеты, видимые на всех страницах.

- `Sidebar.tsx` — плавающий стеклянный сайдбар: навигация, переключатель темы,
  единственный аватар пользователя (пункт «Профиль»).
- `NotificationBell.tsx` — колокольчик уведомлений: лента (аккордеон, максимум одна
  запись раскрыта), пометка прочитанного, автообновление (`refetchInterval`).
- `FeedbackWidget.tsx` — плавающая кнопка обратной связи с формой отправки сообщения.
