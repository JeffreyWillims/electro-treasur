# components/tax

Раздел «Налоги» — детерминированные расчёты и справочник, без LLM.

- `DeductionCalculator.tsx` — «введи сумму → сколько вернёшь»: расчёт налогового
  вычета на сервере (13% с базы в пределах лимита и уплаченного НДФЛ).
- `TaxGuide.tsx` — бесплатный справочник «Налоги и вычеты» с поиском по смыслу
  (Postgres full-text search, без LLM).
