# components

Все React-компоненты приложения, сгруппированы по разделу UI. У каждой подпапки
свой README.md с перечнем файлов.

- `analytics/` — раздел «Аналитика»: графики капитала, психопаспорт, совет дня.
- `auth/` — формы входа и регистрации.
- `budgets/` — раздел «Бюджеты» (конверты, дисциплина, сейф).
- `consultant/` — страница роли CONSULTANT (просмотр клиентов).
- `dashboard/` — раздел «Обзор» и переиспользуемые виджеты дашборда.
- `games/` — Citrine Arcade (мини-игры).
- `insights/` — «AI Анализ» (детерминированный разбор финансов).
- `layout/` — сайдбар, колокольчик уведомлений, виджет обратной связи.
- `profile/` — страница профиля пользователя.
- `tax/` — раздел «Налоги» (калькулятор вычетов, справочник).
- `ui/` — низкоуровневые переиспользуемые примитивы (карточки, скелетоны, date picker).
