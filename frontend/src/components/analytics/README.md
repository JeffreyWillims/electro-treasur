# components/analytics

Раздел «Аналитика»: графики капитала, психопаспорт, симулятор целей, совет дня.

- `MainAnalytics.tsx` — оркестратор раздела: единый `useQuery` дашборда за период,
  собирает вместе `DailyTip`, `HealthScoreCard` и остальные аналитические блоки.
- `CapitalGrowthChart.tsx` — комбинированный график роста капитала (recharts:
  `ComposedChart` — столбцы + линия), с индикаторами тренда (вверх/вниз).
- `PsychopassportCard.tsx` — карточка «Психопаспорт»: заголовок персоны, черты (чипсы)
  и рекомендации; рендерит `null`, если психопаспорт ещё не рассчитан.
- `SavingsNavigator.tsx` — «Горизонт капитала»: график прогноза накоплений (`AreaChart`)
  и калькулятор целей.
- `DailyTip.tsx` — «Совет дня»: ротация подсказок по дню года в зависимости от нормы
  сбережений, свой `useQuery` дашборда.
