# components/dashboard

Раздел «Обзор» и его переиспользуемые части (часть блоков используется и в «Бюджетах»).

- `BalanceCards.tsx` — карточки баланса счетов из дашборда.
- `BudgetConfigModal.tsx` — модалка создания/редактирования лимита бюджета по категории
  (портал в `document.body`, чтобы не обрезаться `overflow-hidden`/`backdrop-blur` родителей).
- `BudgetEnvelopes.tsx` — грид карточек-конвертов бюджета: `BudgetDiscipline` (индекс
  дисциплины), `Safe` («Сейф» — сэкономленное + перенос в цель), сами карточки-конверты.
- `BudgetMatrix.tsx` — таблица Категория → План → Факт → Дельта, перерасход подсвечен красным.
- `CategoryManagerModal.tsx` — полный CRUD пользовательских категорий.
- `CategoryPieChart.tsx` — круговая диаграмма расходов по категориям (recharts).
- `ConfirmDeleteDialog.tsx` — диалог подтверждения удаления категории с защитой от
  каскадного удаления связанных транзакций.
- `DataVaultModal.tsx` — модалка импорта транзакций (drag&drop, .csv/.xlsx/.xls, до 10 МБ).
- `GoalsProgress.tsx` — прогресс целей «Сейф»: пополнение, удаление.
- `HealthScoreCard.tsx` — индекс финансового здоровья 0–100 (норма сбережений, цели, бюджеты).
- `MonthlySummary.tsx` — карточки «Доход/Расход за месяц» с мини-графиками.
- `PurchaseAdvisor.tsx` — «Стоит ли покупать?»: вердикт по свободным деньгам месяца, без LLM.
- `QuickEntry.tsx` — быстрый ввод транзакции (сумма/категория/голос через `VoiceInput`).
- `RecurringReminders.tsx` — умные напоминания о регулярных платежах (localStorage),
  «Готово» создаёт расходную транзакцию.
- `SafeToSpend.tsx` — «Можно потратить»: свободные деньги месяца с учётом бюджетов.
- `SpendingChart.tsx` — столбчатый график расходов по дням/категориям (recharts).
- `StatementImportModal.tsx` — сканирование выписки/чека (PDF/фото/Excel): загрузка →
  фоновый разбор (arq) → живой прогресс (SSE с фолбэком на polling) → превью → импорт.
- `TransactionList.tsx` — бесконечная лента транзакций с инлайн-редактированием.
- `VoiceInput.tsx` — голосовой ввод суммы/категории (Web Speech API, лимит записи 21 сек).
