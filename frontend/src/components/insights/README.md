# components/insights

«AI Анализ» — детерминированный (без LLM) разбор финансов пользователя.

- `InsightModal.tsx` — окно анализа: скелетон на время расчёта → карточки
  (итог → наблюдения → совет) → действия (скопировать текст, скачать PDF-план).
- `InsightHistory.tsx` — свёрнутый по умолчанию таймлайн прошлых ежемесячных
  анализов (`GET /v1/insights`), раскрывается по клику.
