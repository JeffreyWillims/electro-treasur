# components/games

Citrine Arcade — мини-игры на финансовую тему с рекордами (`@/lib/gameRecords`).

- `GamesHub.tsx` — витрина аркады: список игр, топ-100 лидерборд, запуск конкретной игры.
- `Game512.tsx` — «Купюра 512 ₽»: 2048-механика, плитки — номиналы рублей (1 ₽ → … → 512 ₽).
- `PiggyBank.tsx` — «Копилка»: аркада вместо змейки, ловим монеты/купюры, уклоняемся от
  импульсивных трат; уровни растут каждые 500 ₽ капитала.
