# components/ui

Переиспользуемые низкоуровневые UI-примитивы.

- `Card.tsx` — базовая стеклянная (glassmorphism) поверхность-контейнер.
- `Skeleton.tsx` — плейсхолдер `animate-pulse` на время загрузки асинхронных данных.
- `GlassDatePicker.tsx` — стеклянный календарь выбора одной даты.
- `GlassDateRangePicker.tsx` — стеклянный выбор диапазона дат: пилюля-триггер,
  всплывающая панель с пресетами и сеткой календаря.
- `PacificRide.tsx` — «Десятка» 🔟 (техническое имя компонента — Pacific Ride):
  игра «числа-совпадения» (Number Match / Семечки), 3 уровня сложности, пасхалка аркады.
