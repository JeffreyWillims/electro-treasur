# lib

Утилиты общего назначения, не привязанные к конкретному компоненту.

- `categories.ts` — словарь перевода названий категорий (англ. ключи бэкенда → русские подписи UI).
- `dateUtils.ts` — модуль работы с датой/временем со строгой привязкой к МСК (UTC+3) —
  все «текущий месяц»/«сегодня» в приложении считаются по московскому времени.
- `gameRecords.ts` — рекорды игр Citrine Arcade: localStorage + фоновая (debounced)
  синхронизация с бэкендом (топ-100), чтобы серия рекордов не спамила API.
- `queryClient.ts` — общий инстанс `QueryClient`, вынесен отдельно, чтобы избежать
  циклических импортов между `App.tsx` и `AuthContext.tsx`.
- `utils.ts` — хелпер `cn()` (clsx + tailwind-merge) для условного объединения классов
  без конфликтов Tailwind (например `p-4` против `p-2`).
